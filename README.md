# 风序 WindSec · SDL 安全开发管理平台

面向风电出海样机的中文 IEC 62443-4-1 ML2 制度与执行管理网页。

## 启动

需要 Python 3。在仓库目录执行 `npm start`（或 `python3 -m http.server 3000 --bind 0.0.0.0`），浏览器打开 http://localhost:3000。

应用无运行时 npm 依赖，无构建步骤。字体为可选网络资源，离线时自动使用系统字体。

## 功能

- 总览：完成率、风险、证据、八大实践与生命周期门禁。
- 制度中心：12 项制度底稿，要求、证据、搜索及实践筛选。
- 执行任务：创建、编辑、完成、重新打开，按状态或逾期筛选。
- 阶段门禁：评审人、依据与结论，前序门禁检查。
- 风险与例外：等级、责任人、措施、审批记录、关闭及接受管理。
- 证据档案：登记文件位置、产品版本及审核状态，不托管附件。
- JSON 导出：包含制度与全部管理记录，可留存备份；当前不提供导入。

首次打开使用明确标识的演示项目及数据。修改保存在当前浏览器 localStorage，刷新后保留。清理站点数据会删除记录。

这是单浏览器管理原型，没有服务器数据库、身份认证、权限控制、多人协作、电子签名或不可篡改审计。请勿把本地审批记录当作正式授权，勿录入密钥或敏感参数。

制度是实施底稿，正式受控发布应根据授权标准原文核对；任务完成率不是认证结论，ML2 不等于产品 SL2。

## 验证

`npm ci --cache /tmp/wind-npm-cache`

使用系统 Chromium（默认 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定其他路径）。

先启动服务，再执行 `npm test`。测试实际操作任务、证据、风险、门禁、导出及移动端布局，并验证本地持久化。
